# Connect6Go
A boardgame that combines the rules of connect5 and Go.

## 游戏规则：
胜利条件：率先在任何方向（横竖斜）连成6颗同色棋子。
反击机制：达成六连后，允许对手再下一手。若对手能通过提子破坏你的六连，则游戏继续；若对手无法破坏，则判定你获胜。
气：棋子旁边的空位。没有“气”的棋块会被立即从棋盘提掉。
禁手：不能下在没有气且不能吃掉对方的位置（禁止自杀）。
劫争：如果你的落子会导致棋盘状态瞬间回到上一回合，则被禁止。
悔棋：需对方同意后方可回滚至上一回合。
